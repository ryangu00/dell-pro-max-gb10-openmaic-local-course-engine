# Synthetic fixtures

These files are handwritten test inputs. They contain no original prompt,
course prose, role personas, output records, screenshots or run logs.
They are not a fresh course generated by OpenMAIC and have no generation timings.

| File | Purpose |
|---|---|
| `scene-clean.json` | Separated text boxes accepted by the geometry checker |
| `scene-overlap.json` | Stacked text boxes that exercise identical-origin findings |
| `scene-outside.json` | A shape crossing the fixed canvas boundary |
| `interactive.html` | Exact pinned CDN references for a text-rewriting test |
| `metrics/running.prom` | A synthetic busy endpoint, with one metric series per counter |
| `metrics/idle.prom` | A synthetic idle endpoint using the source script's decimal formatting |

The geometry and metrics values are fixture constants, not additional measurements.
The JSON files deliberately exercise only the layout checker's input contract;
they are not complete importable course packages. The HTML contains asset references,
not a working interactive lesson. Do not open it online as a substitute for the
offline rewrite test.

The shell tests supply fake `curl`, `date` and `sleep` commands. They make no
network requests and do not wait for the real monitoring intervals.
The JavaScript tests supply an IndexedDB mock and a mock `fetch`; they do not
validate a real browser's transaction scheduling, CORS or classroom playback.

A fresh neutral course, generated with a reader-provided endpoint, remains a
separate exercise. Its timings will differ from the historical results.
